## Colaboración
Ambas cuentas deben abrir ESTE repositorio en Codex con permisos de escritura. Actualizar desde main antes de trabajar. Guardar cambios en una rama y abrir un pull request; integrar en main para compartir la versión oficial. Un chat normal o un enlace no concede acceso al repositorio.

## Vista local
Ejecutar python3 -m http.server 8000 --directory dist y abrir http://localhost:8000.
